# Обучение сети «Мастера» на видеокарте

Набор, чтобы за сутки или неделю на компьютере владельца обучить сеть седьмого уровня «Мастер» (внутреннее имя
`neural`). Зачем, как устроена сеть и когда она идёт в игру — [спецификация](../../docs/specs/2026-11-neural.md).
Устройство набора — по образцу `tools/gpu/` «Нард» (`Nefeste/nardy`), с одним отличием: правила **не переписаны на
Python**. Партии играет сам движок приложения в Bun, а Python с видеокартой только учит сеть.

Как это работает:

- **Партии — Bun на процессоре.** На каждое ядро — свой процесс `selfplay.ts`. Он играет партии на 2–4 места в
  подкидной и переводной: движок приложения, боты приложения, сеть — тот же код, что в игре. Ошибиться в правилах
  негде.
- **Обучение — PyTorch на видеокарте.** Сеть учится на наблюдениях мест из этих партий. Признаки на Python
  (`features.py`) совпадают с признаками приложения бит в бит — это проверяет `selftest.py`.
- **Круги внахлёст.** Пока процессы играют следующий круг, видеокарта учит сеть на предыдущем.
- **Два этапа.** Первый — TD(λ): сеть ходит по своей оценке, быстро. Его длина — половина времени, но не больше
  24 ч. Второй — «поиск»: сеть ходит, как будет ходить в игре (расклады и доигрывание отбоя), и учится ещё и на
  оценке этого поиска.
- **Арена раз в час.** Сеть играет против «Сильного» (`experienced`) и «Опытного» (`master`) — настоящих ботов
  приложения — и против сети-пилота, на зеркальных раздачах. После арены пишутся снимок весов и строка в журнале.

Главная работа здесь — партии, а их считает процессор: сеть небольшая (её надо считать на телефоне), и видеокарта
учит её за секунды. Поэтому важно оставить процессор обучению. Видеокарта тоже нужна, но загружена будет мало, и это
нормально.

## Что нужно

- Windows 10/11 или Linux, видеокарта NVIDIA (RTX 20xx и новее) со свежим драйвером. Без видеокарты тоже работает,
  только обучение сети идёт на процессоре и отнимает ядра у партий.
- **Python 3.12** (подойдут 3.10–3.13), как для «Нард»: https://www.python.org/downloads/ — на Windows при установке
  отметить «Add python.exe to PATH».
- **Bun** 1.3 или новее: https://bun.sh. Установка — в шаге 2.
- Git и репозиторий `Nefeste/durak`; около 2 ГБ места (torch — 1,5 ГБ, прогон — десятки мегабайт).
- Компьютер не должен засыпать (шаг 5).

`npm ci` для обучения не нужен: Bun запускает движок и ботов без `node_modules`.

## Шаги

### 1. Ветка

В папке репозитория `durak` (если его ещё нет на этом компьютере — `git clone https://github.com/Nefeste/durak.git`,
затем `cd durak`):

```
git fetch origin
git checkout claude/neural
git pull
```

Когда PR с набором сольют, вместо `claude/neural` — `main`.

### 2. Окружение (один раз)

**Windows** (PowerShell, в папке репозитория):

```
powershell -c "irm bun.sh/install.ps1 | iex"
py -3.12 -m venv .venv-gpu
.venv-gpu\Scripts\activate
python -m pip install --upgrade pip
pip install -r tools/gpu/requirements.txt
pip install torch --index-url https://download.pytorch.org/whl/cu128
```

После установки Bun **закрыть и открыть PowerShell заново**: так новое окно увидит `bun`. Потом снова войти в папку
репозитория и выполнить `.venv-gpu\Scripts\activate`. Проверка — `bun --version`.

Если Bun уже стоит (им запускали ночное обучение «Нард»), первую строку можно пропустить. Если `activate` пишет, что
выполнение сценариев отключено, один раз выполнить `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и ответить «Y».

**Linux**:

```
curl -fsSL https://bun.sh/install | bash
python3.12 -m venv .venv-gpu
source .venv-gpu/bin/activate
python -m pip install --upgrade pip
pip install -r tools/gpu/requirements.txt
pip install torch --index-url https://download.pytorch.org/whl/cu128
```

`cu128` — сборка torch под CUDA 12.8, подходит для RTX 20xx–50xx при свежем драйвере. Для RTX 3060 Ti — она же.

### 3. Проверка (около минуты)

Каждый раз в новом окне PowerShell сначала войти в папку репозитория и выполнить `.venv-gpu\Scripts\activate`
(Linux — `source .venv-gpu/bin/activate`).

```
python tools/gpu/selftest.py
```

Что должно быть:

- «эталон признаков: 1500 наблюдений, расхождений признаков 0»;
- «свежие партии: … расхождений признаков 0»;
- имя видеокарты: «видеокарта: NVIDIA GeForce RTX 3060 Ti»;
- скорость обучения и самоигры;
- в конце — **«ВСЁ В ПОРЯДКЕ — можно запускать обучение»**.

Если вывод другой, обучение не запускать: прислать вывод целиком.

### 4. Пробный час

```
python tools/gpu/train.py --hours 1 --out tools/gpu/runs/test
```

Журнал печатается на экран и пишется в `tools/gpu/runs/test/log.txt`. Пробный час — это 30 минут TD и 30 минут поиска,
арена — в конце (первая арена всегда через час после запуска, потом — каждый час). После часа прислать последние 20 строк журнала (шаг 7): по ним видно, хватает ли
скорости и растёт ли сила. Если что-то не так, числа для долгого запуска поправим.

### 5. Сутки или неделя

Сначала — чтобы компьютер не заснул. Windows, в PowerShell:

```
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
```

Обновления Windows могут перезагрузить компьютер ночью. Чтобы этого не было: «Параметры» → «Центр обновления Windows»
→ «Приостановить обновления на 1 неделю». Монитор гаснуть может, это обучению не мешает.

Затем — одна из команд:

```
python tools/gpu/train.py --hours 24
```

```
python tools/gpu/train.py --hours 168
```

`24` — сутки (12 ч TD, 12 ч поиска), `168` — неделя (24 ч TD, 144 ч поиска). Папка прогона — `tools/gpu/runs/main/`.

- **Остановить** — **Ctrl+C**. Снимок сохранится сразу, без ожидания конца круга. Второй Ctrl+C — выйти без сохранения.
- **Продолжить** — запустить **ту же команду**: обучение пойдёт с места. Считается только время обучения,
  перерывы в него не входят.
- **Сутки, потом неделя.** Если после суток решили учить неделю, запустить ту же папку с `--hours 168`. Этап TD к этому
  времени уже пройден, сразу пойдёт поиск.
- **Компьютер нужен для работы.** `--threads 4` оставит часть ядер свободными; по умолчанию процессов на два меньше,
  чем потоков процессора (на i5-12400F — 10).
- Перед продолжением после перерыва стоит обновить код: `git pull`. Папки `tools/gpu/runs/` и `.venv-gpu` в git не
  входят, `git pull` их не тронет.

### 6. Как понять, что всё идёт хорошо

Раз в минуту-две в журнале — строка круга:

```
круг 120: TD, партий 1,450,000 (+4000 за 25 с, 160/с), примеров 312,000, ошибка на новом 0.5810, после обучения 0.5795, шаг 9.6e-04, обучение 4 с; сеть за столами с ботами не дурак в 0.712 (как все — 0.660); 2.10 ч из 168
```

- **«партий … /с»** — скорость. На этапе TD на i5-12400F ожидается 100–200 партий в секунду, на этапе поиска — 40–80.
- **«ошибка на новом»** — ошибка сети на партиях, которых она ещё не видела. Первые часы падает, потом стоит около
  0,55–0,60. Это нормально: исход партии с картами соперников наугад предсказать точно нельзя.
- **«сеть за столами с ботами не дурак в …»** — как часто сеть не остаётся с картами за столами, где с ней сидят
  боты-уровни. «Как все» — сколько было бы при равной силе. Сеть выше «как все» — сильнее ботов-уровней в смеси.

Раз в час — строка арены:

```
== арена: против «Сильного» 0.800 ± 0.028 (Эло +241, …); против «Опытного» 0.760 ± 0.030 (Эло +200, …); против «пилота» 0.560 ± 0.034 (Эло +42, +18…+66); 240 с
```

- **Доля** — партии один на один, где сеть не осталась с картами. ± — 95-процентный интервал: 400 партий на соперника.
- **«Пилот»** — сеть, которую агент учил 30 минут на процессоре песочницы, 09.11.2026
  (`tools/gpu/nets/2026-11-09-cpu-pilot/`). Она уже обыгрывает «Опытного» в 73 % из 800 партий. Порог приёмки —
  60 % против «Опытного» (`docs/10-bot.md`): пилот его, похоже, проходит, если подтвердит его арена на 2 000 партий.
- **Зачем обучение у владельца.** Получить сеть заметно сильнее пилота: с запасом над порогом, сильнее за столом на
  3–4 места, с очередью атакующих (#57).
- **Главное число — против «пилота».** Выше 0,5 — новая сеть сильнее пилота; 0,55 и выше несколько арен подряд — её
  пора присылать.
- **Против «Опытного»** доля должна быть выше 0,7 через несколько часов.
- `best.bin` — лучший снимок по арене против «Опытного»; в журнале — строка «лучший снимок обновлён».
- `progress.jsonl` — те же числа построчно, из них строится кривая.

### 7. Отправить результат

**После пробного часа** хватит текста: последние 20 строк `tools/gpu/runs/test/log.txt` в комментарий к Issue или в
чат.

**После суток, раз в 2–3 дня недели и в конце** — веса:

```
python tools/gpu/collect.py
git checkout -b train/neural-<дата>
git add tools/gpu/nets
git commit -m "Обучение сети: веса и журнал"
git push -u origin train/neural-<дата>
```

`collect.py` собирает в `tools/gpu/nets/<дата>-main/` около 3 МБ:

- `best.bin` и `best.json` — лучшая сеть по арене (620 КБ);
- `last.bin`, `last.json` — последняя сеть;
- `last.pt` — снимок, с которого можно учить дальше;
- `log.txt`, `progress.jsonl` — журнал и кривая.

Собирать можно, не останавливая обучение. Коммит — в новой ветке, не в `main`. Если `git push` не проходит, можно
заархивировать папку `tools/gpu/nets/<дата>-main` и приложить архив к Issue.

Дальше — в сессии разработки: арена приложения на 2 000 партий против «Опытного», замер на телефоне, встраивание
(спецификация, «Как сеть попадает в игру»).

## Если что-то не так

- **«видеокарты НЕТ»** в проверке. Проверить, что `nvidia-smi` в PowerShell показывает карту и драйвер 570 или новее;
  если нет — обновить драйвер NVIDIA (https://www.nvidia.com/drivers). Затем переустановить torch:
  `pip uninstall -y torch`, потом снова `pip install torch --index-url https://download.pytorch.org/whl/cu128`.
  Проверка: `python -c "import torch; print(torch.cuda.is_available())"` должна напечатать `True`. Без видеокарты
  обучение тоже идёт, только медленнее.
- **«Bun не найден».** Открыть новое окно PowerShell после установки Bun. Если не помогло, указать путь:
  `--bun C:\Users\<имя>\.bun\bin\bun.exe`.
- **«в … учится другая сеть».** В этой папке прогона сеть другого размера. Нужен другой `--out` или прежний `--hidden`.
- **Процесс Bun упал.** В журнале будет текст ошибки. Прислать его; обучение продолжится той же командой с последнего
  снимка.
- **Компьютер перезагрузился.** Запустить ту же команду: потеряется не больше одного круга.

## Файлы

| Файл | Что |
|---|---|
| `train.py` | обучение: круги самоигры, обучение, арена, снимки, журнал |
| `selftest.py` | проверка перед обучением |
| `collect.py`, `export.py` | собрать итог в `nets/`; веса из любого `.pt` в `.bin` |
| `features.py` | признаки на Python — те же, что `src/bot/net/features.ts` |
| `model.py` | сеть и её файл `.bin` для TypeScript |
| `common.py` | где Bun, запуск процессов |
| `selfplay.ts` | самоигра в Bun: партии, цели, файл примеров |
| `arena.ts` | арена сети против уровней приложения, параллельно |
| `vectors.ts`, `vectors/` | эталон признаков и оценки: случайная маленькая сеть `tiny.bin`, 1 500 наблюдений |
| `play.ts` | общее для самоигры и арены |
