# Арена этапа Д — шесть уровней

08.11.2026, движок `durak-rules-v1`, боты `src/bot/` версии 0.5.0. Решение владельца
[#15](https://github.com/Nefeste/durak/issues/15), вариант 1: «Сильный» и «Мастер» сливаются в один «Мастер»,
седьмое место — «Нейросеть», закрыто до нейросети.

Новый уровень «Мастер» — прежний «Мастер» без изменений: 128 раскладов и точная концовка вдвоём до 15 000 узлов.
Поэтому новой осталась одна пара — «Мастер» против «Опытного». Остальные пары этот этап не трогал, их числа — из
[отчёта этапа В](2026-11-08-arena-stage-v.md).

Команда: `bun tools/sim/arena.ts 200 master experienced <вариант> <зерно>` — 200 колод, 400 партий на зеркальных
раздачах (каждая колода дважды, места меняются). Доля — партии, где «Мастер» не остался с картами (ничья — половина),
в скобках — 95-процентный интервал.

## Лестница

| A против B | Подкидной | Переводной | 60 %? |
|---|---|---|---|
| Начинающий — Новичок | 67,5 % [65,5 … 69,6] | 69,7 % [67,7 … 71,7] | да |
| Любитель — Начинающий | 63,1 % [61,0 … 65,2] | 63,3 % [61,2 … 65,4] | да |
| Средний — Любитель | 61,0 % [58,9 … 63,2] | 63,4 % [61,3 … 65,5] | да |
| Опытный (4 расклада) — Средний | 65,3 % [60,6 … 69,9] | 66,0 % [61,4 … 70,6] | да |
| **Мастер (128 + концовка) — Опытный** | **60,6 % [55,8 … 65,4]** | **61,8 % [57,0 … 66,5]** | да, по оценке; нижняя граница интервала — ниже 60 % |

Партий, не кончившихся за 5 000 действий, не было.

## Что это значит

- Все пять ступеней шести уровней выполняют правило 60 % (`10-bot.md`, «Цель лестницы»).
- У верхней ступени запас малый: 400 партий не отличают 60,6 % от 57 %. Если владельцу в игре «Мастер» покажется
  слишком близким к «Опытному», «Опытного» можно ослабить до 2 раскладов — это следующий замер, не этого этапа.
- Седьмой уровень — нейросеть (`10-bot.md`, «Нейросеть — седьмой уровень»): цель для него та же — 60 % против
  «Мастера».
