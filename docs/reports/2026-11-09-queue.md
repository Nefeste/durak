# Очередь атакующих и боты — замер 09.11.2026

Решение владельца [#57](https://github.com/Nefeste/durak/issues/57): по умолчанию подкидывают по очереди, «кто успел» —
настройка стола ([`08-rules.md`](../08-rules.md), п. 4.3; ADR [0013](../adr/0013-throw-order.md)). Вопрос замера:
меняет ли очередь силу и порядок уровней.

## Почему боты играют одинаково при обоих сводах

Арена, доигрывание поиска и стол с ботами дают ход **первому месту от ходящего по часовой стрелке, у которого есть
законные действия** (`actorOf`, `actorFast`, `botToAct`). Это и есть очередь: ходящий, пока не сказал «пас»; затем
отбивающийся, если есть что крыть; затем следующий атакующий, кто ещё не сказал «пас». Поэтому за столом из одних
ботов «кто успел» и «по очереди» дают одну и ту же партию до действия. Разница — только у людей, которые могут
положить карту раньше очереди (с ботами и онлайн).

## Числа

`bun tools/sim/arena.ts table <раздач> <a> <b> <мест> <вариант> <зерно> <free|queue>` — уровень `a` на одном месте,
остальные `b`, место `a` по кругу; «отпечаток» — хеш итогов и сбросов всех партий.

| Стол | Свод | Партий | `a` без карт | Как все | Отпечаток |
|---|---|---|---|---|---|
| «Средний» против «Любителей», трое, подкидной | кто успел | 450 | 73,0 % | 66,7 % | `9faa1774` |
| то же | по очереди | 450 | 73,0 % | 66,7 % | `9faa1774` |
| «Средний» против «Любителей», четверо, переводной | кто успел | 400 | 83,1 % | 75,0 % | `872a773e` |
| то же | по очереди | 400 | 83,1 % | 75,0 % | `872a773e` |
| «Сильный» против «Средних», трое, подкидной | кто успел | 90 | 75,0 % | 66,7 % | `4b50559d` |
| то же | по очереди | 90 | 75,0 % | 66,7 % | `4b50559d` |

Отпечатки совпадают: партии те же до карты. Лестница уровней ([отчёт этапа Д](2026-11-08-arena-stage-d.md)) —
один на один, там атакующий один и сводов не различить; её числа в силе без перезамера.

## Что проверяют тесты

- `tools/test/rules.test.ts` — золотые тесты очереди: право у ходящего, «пас» передаёт право дальше, новая карта
  (подкинутая, покрытая, переведённая) начинает круг заново, «вдогонку» — тем же кругом, атакующий без карт в круг
  не входит, вдвоём своды равны, записи `durak-rules-v1` играются «кто успел».
- `tools/test/games.test.ts` — случайные партии на обоих сводах; у очереди не в свою очередь законных действий нет.
- `tools/test/search.test.ts` — быстрое доигрывание равно правилам «Среднего» на обоих сводах (40 000 позиций).
- `tools/test/observe.test.ts` — уровни решают одинаково на позиции и её двойнике на обоих сводах.
- `tools/test/server.test.ts` — стол «по очереди» втроём онлайн до конца, отказ не в свою очередь (`waitTurn`),
  старой версии игры за такой стол нельзя (`426`), её стол — «кто успел».
