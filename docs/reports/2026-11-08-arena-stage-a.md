# Арена этапа А — уровни по правилам

08.11.2026, движок `durak-rules-v1`, боты `src/bot/rules.ts`. Команда:
`bun tools/sim/arena.ts 1000 <A> <B> <стол> 1` — 1 000 колод, каждая дважды с обменом мест (2 000 партий), один на
один. Доля — партии, где уровень A не остался с картами (ничья — половина); в скобках — 95-процентный интервал.

| A против B | Подкидной | Переводной |
|---|---|---|
| Начинающий — Новичок | 67,7 % [65,7 … 69,7] | 67,0 % [65,0 … 69,1] |
| Любитель — Начинающий | 59,6 % [57,4 … 61,8] | 63,5 % [61,4 … 65,7] |
| Средний — Любитель | 56,1 % [54,0 … 58,3] | 59,6 % [57,4 … 61,7] |
| Средний — Новичок | 81,7 % [80,0 … 83,4] | 82,3 % [80,6 … 84,0] |

**Что значит.** Лестница идёт вверх на всех ступенях, но цель `10-bot.md` — каждый уровень обыгрывает соседа
не меньше чем в 60 % — пока выполнена не везде: «Средний» над «Любителем» в подкидном — 56 %, «Любитель» над
«Начинающим» — около 60 %. Уровни различаются долей случайных ходов, береженьем козырей и подкидыванием; сила
«Среднего» упирается в ручные правила. Этап В добавит поиск по раскладам («Опытный» … «Мастер»), тогда ступени
пересоберутся: правило лестницы — сжать уровни, а не подкручивать карты.
