# Документация проекта «Дурак»

Здесь всё, что нужно, чтобы вести проект, ничего не помня о нём заранее. Документы живут рядом с кодом и
меняются вместе с ним: правка кода без правки документа — незакрытая задача.

Где проект сейчас — [`STATUS.md`](../STATUS.md). Документы `02`–`04` и `08`–`10` описывают то, что **будет**
в коде до первой строки кода; когда код появится, они описывают то, что есть, а расхождение правится в том же
коммите. Номера версий — всегда X.Y.Z ([`05-process.md`](05-process.md), «Версии»).

## Порядок чтения

1. [`01-product.md`](01-product.md) — что за игра, для кого, что обещаем и чего сознательно нет; словарь.
2. [`08-rules.md`](08-rules.md) — правила подкидного и переводного: единственное место, где они записаны.
3. [`09-game-design.md`](09-game-design.md) — режимы, экраны, управление, реклама и покупки глазами игрока.
4. [`02-architecture.md`](02-architecture.md) — приложение и сервер, что берём из «Нард».
5. [`03-server-api.md`](03-server-api.md) — протокол: столы, ходы, события, что видит каждое место.
6. [`04-data-model.md`](04-data-model.md) — данные в движке, на телефоне и на сервере.
7. [`10-bot.md`](10-bot.md) — боты, точный расчёт концовки, разбор, задача дня.
8. [`05-process.md`](05-process.md) и [`06-testing.md`](06-testing.md) — версии, CI, выпуск, проверки.
9. [`07-roadmap.md`](07-roadmap.md) — этапы и вопросы владельцу.
10. [`11-money.md`](11-money.md), [`12-market.md`](12-market.md) — деньги, право, рынок.

Решения, которые дорого менять, — [`adr/`](adr/README.md). Возможности до кода — [`specs/`](specs/);
живая спецификация — [`specs/2026-11-v1.md`](specs/2026-11-v1.md). Журнал — `journal/ГГГГ-ММ.md`.

## Правила этих документов

Общие правила документов — устав, [`docs/04-process.md`](https://github.com/Nefeste/gornitsa/blob/main/docs/04-process.md).
Здесь добавлено одно:

- **Одно место для числа.** Правила игры — только в `08-rules.md`. Числа геймдизайна (сколько партий без
  рекламы, уровни, цены) — только в `09-game-design.md`. Числа бота — только в `10-bot.md`. Остальные
  документы ссылаются на них.
