# 0009. Деньги как у «Нард»: реклама между партиями, «Без рекламы», «Про», оформления

**Решили.** Бесплатная игра; полноэкранная реклама только между партиями по правилам частоты «Нард»; реклама за
вознаграждение по желанию; «Без рекламы» навсегда; «Про» подпиской — полный разбор всех партий и подробная
статистика; оформления наборами. Помощники против ботов (подсказка, вышедшие карты, отмена) — бесплатно всем.
Числа — [`09-game-design.md`](../09-game-design.md). **Ждёт решения владельца** (вопрос 5 этапа 0): устав сейчас
разрешает рекламный SDK только «Нардам».

**Почему.** Та же аудитория, тот же код, проверенный в RuStore. Партии короче нард — больше показов при тех же
правилах.

**Платим.** Рекламный SDK в APK (+ разрешение `AD_ID`); доход зависит от удержания, а не от цены.
