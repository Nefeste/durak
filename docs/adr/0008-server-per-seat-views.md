# 0008. Сервер «Нард» на машине сайта; каждому месту — только его вид

**Решили.** Сервер — копия сервера «Нард» (Bun + SQLite, машина сайта в России, `durak.gornitsa.games`, ADR 0005 и
0018 «Нард»). Отличие: каждый ответ и каждое событие собираются **для места** функцией движка `observe`. Чужие руки и
порядок колоды не уходят с сервера до конца партии. Тест обходит все маршруты и события и проверяет это.

**Почему.** В нардах всё видно на доске; в дураке утечка одной руки — это и есть «подкрутка». Одна функция
наблюдения для бота, экрана и сервера — одно место, где можно ошибиться, и один тест.

**Платим.** Рассылка событий по местам: N сборок вида на событие вместо одной. При 4 местах это ничего не стоит по
нагрузке, но протокол «Нард» меняется, и телефоны «Нард» и «Дурака» несовместимы — у каждой игры свой сервер.
