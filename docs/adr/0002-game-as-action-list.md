# 0002. Партия — расстановка, порядок колоды и список действий

**Решили.** Партия описывается расстановкой (свод, вариант, места, первый ход), порядком колоды (36 чисел) и
списком действий. Движок детерминирован; порядок колоды ему передают. Сохранение — эти данные, восстановление —
переигрывание. Как ADR 0002 «Нард», где вместо колоды — броски.

**Почему.** Один формат для сохранения, онлайна, проверки сервером, разбора, статистики и задачи дня.

**Платим.** Колода с ботами лежит в записи на телефоне с начала партии — значит, ботам и экрану её нельзя давать
(ADR 0005). Изменение правил ломает старые записи — поэтому версия свода в записи (ADR 0003).
