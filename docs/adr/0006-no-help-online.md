# 0006. Онлайн — ни подсказок, ни счёта карт, ни разбора до конца партии, ни у кого

**Решили.** В онлайн-партии нет подсказки, таблицы вышедших карт, отмены и разбора — ни бесплатно, ни за деньги.
Разбор — после конца партии. Как ADR 0012 «Нард».

**Почему.** Деньги не покупают преимущество над человеком (устав, «Деньги»). Счёт карт против человека — тоже
преимущество, если он у одного.

**Платим.** Новички онлайн играют без помощи. Помощники есть против ботов — бесплатно.
