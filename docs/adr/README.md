# Принятые решения (ADR)

Короткие записки о решениях, которые дорого менять: что решили, почему, чем платим. Читать **до** того, как
предлагать обратное. Новая записка — новый файл `NNNN-краткое-название.md`; решения не переписываются задним
числом — пишется новая записка «заменяет NNNN».

Многие решения унаследованы от «Нард» (`Nefeste/nardy`, `docs/adr/`); где так, записка говорит, что взято и что
изменилось. Решения устава здесь не повторяются — на них ссылаются.
