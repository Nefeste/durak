# 0010. Карты рисует код: русские индексы, без фигур и чужих колод

**Решили.** 36 лиц и рубашку рисует код (Skia) из данных: индексы **В, Д, К, Т** и числа, значки мастей, на
картинках — крупная буква и орнамент масти вместо фигуры; рубашка — своя (облик — ADR [0012](0012-own-look.md)). Один холст на стол, карты —
картинки, нарисованные один раз. Генераторов изображений нет (устав).

**Почему.** Свои права на всё, один стиль, лёгкая правка; русские индексы — узнаваемо и своё. Фигуры людей кодом
нарисовать хорошо трудно, а копировать колоды (атласные, «русский стиль») нельзя.

**Платим.** Нет «живых» королей и дам — кому-то колода покажется простой. Платные оформления — тоже кодом.
