# 0005. Бот видит только наблюдение своего места; тест одинаковости

**Решили.** Боты, подсказка и разбор получают `observe(state, seat)` — то, что видит игрок на этом месте, — и
ничего больше. `src/bot/` не импортирует колоду и полную позицию (правило линтера). Тест: на парах позиций с одним
наблюдением и разными скрытыми картами каждый уровень выбирает одно действие.

**Почему.** «Бот знает карты» — вторая по частоте жалоба карточных игр. Тест делает обещание проверяемым кодом, а не
словами.

**Платим.** Сильный бот считает расклады сам — это медленнее и сложнее, чем подсмотреть (ADR не позволяет срезать
путь даже для «Мастера»). Слабые уровни забывают карты по правилу, а не случайно на глаз.
