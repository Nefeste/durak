# 0011. Боты за столом — только с подписью «бот» и именем уровня (уточнено 0014)

> **10.11.2026.** Решением владельца [#20](https://github.com/Nefeste/durak/issues/20) «называется по уровню, без
> человеческих имён» заменено: у бота — имя персонажа, портрет кодом, подпись «бот» и уровень — ADR
> [0014](0014-rivals-with-names.md); там же — чем платим. Всё остальное ниже в силе: подпись «бот» всегда, боты на
> пустых местах — с согласия создателя, в быстрой игре — явно, «играет бот за Имя».

**Решили.** Бот за столом всегда подписан «бот», называется по уровню («Средний»), без человеческих имён и аватаров
людей. На пустых местах стола с друзьями боты садятся только с согласия создателя; в быструю игру бот предлагается
явно («Сыграть с ботом, пока ищем?»). Когда за игрока без связи играет бот — «играет бот за Имя». Как ADR 0011
«Нард», с одним отличием: за одним столом могут быть люди и боты сразу.

**Почему.** Бот никогда не выдаётся за человека (устав, «Честность»).

**Платим.** Нельзя «оживить» пустую быструю игру ботами под видом людей — так делают конкуренты.
