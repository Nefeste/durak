# Протокол сервера

Копия протокола «Нард» ([`Nefeste/nardy`, `docs/03-server-api.md`](https://github.com/Nefeste/nardy/blob/main/docs/03-server-api.md))
с тремя отличиями: за столом **2–4 места**, сервер отдаёт **вид места**, а не всю партию, и случайность — это
**порядок колоды**. Ниже — то, что отличается; всё, что не названо, работает как в «Нардах»: ключ устройства в
`Authorization`, версия в `X-Durak-Version`, `426 upgrade`, пределы, коды ошибок, повтор запроса, страницы сайта,
ежедневная статистика, удаление профиля.

Общие с телефоном типы — `src/state/protocol.ts`; колода — `src/engine/deck.ts`.

## Столы

Стол — место встречи 2–4 игроков по коду. `game` — номер партии за столом с нуля; `n` — номер **действия** в
партии с нуля. `kind`: `friend` — с друзьями по коду, `quick` — быстрой игры (только два места).

### Создать и войти

`POST /v1/tables`

```json
{ "rid": "3f2c…", "variant": "perevodnoy", "seats": 4, "bots": "average", "seed": "a1b2…(32)" }
```

→ `201 {"table": TableView}`. `seats` — 2…4; `bots` — уровень ботов на свободные места или `null` (не сажать).
В ответе — отпечаток зерна сервера первой партии `commit`.

Вход — в два шага, как в «Нардах»: телефон записывает отпечаток **до** того, как отдаёт своё зерно.

- `GET /v1/tables/code/K7M2QX` → `{"id","host","variant","seats","taken","status","commit"}`.
- `POST /v1/tables/join` `{"code","seed","commit"}` → `200 {"table": TableView}`; `409 commit-changed`, если
  отпечаток сменился; `409 full`, если мест нет.
- `POST /v1/tables/:id/start` — создатель начинает партию; свободные места занимают боты (если `bots` не `null`),
  иначе `409 not-enough` при одном игроке.
- `POST /v1/tables/:id/cancel` — создатель закрывает стол до начала.

### `TableView` — что видит место

```json
{
  "id": "t_9x…", "kind": "friend", "code": "K7M2QX", "status": "playing",
  "variant": "perevodnoy", "rules": "durak-rules-v1",
  "seats": [ { "name": "Миша", "tag": "AB12CD", "bot": null, "online": true, "cards": 6, "out": false },
             { "name": "Средний", "tag": null, "bot": "average", "online": true, "cards": 5, "out": false } ],
  "you": 0,
  "game": {
    "no": 0, "commit": "e3b0…", "n": 17,
    "view": { "hand": [3, 12, 20, 27, 31, 35], "trump": 26, "talon": 11, "table": [[5, 8], [14, null]],
              "discard": [0, 9], "openly": [[], [22]], "attacker": 1, "defender": 0, "passed": [false, false],
              "bout": 4 },
    "deadline": 1790000000000, "bank": [60000, 55200],
    "result": null, "proof": null, "nextCommit": null, "rematch": []
  }
}
```

- `view` — ровно наблюдение места `you` из движка (`observe`, ADR [0008](adr/0008-server-per-seat-views.md)):
  своя рука, козырь, сколько в прикупе, стол парами «атака — защита», сброс, что каждый взял в открытую, кто
  ходит и отбивается, кто сказал «пас». **Чужих рук и порядка прикупа здесь нет никогда.**
- `bot` у места — уровень бота или `null`. У бота нет `tag`: профиля на сервере у него нет.
- `result` — после партии: `{"fool": 2 | null, "order": [0, 3, 1, 2], "draw": false}`.
- `proof` — после партии: `{"seed": "<зерно сервера>", "seeds": ["…", "…"], "deck": [36 чисел]}`. По нему
  телефон пересобирает колоду и сверяет каждую карту, которую видел (`replay.ts`).

### Действие

`POST /v1/tables/:id/act`

```json
{ "game": 0, "n": 17, "action": { "type": "beat", "card": 21, "on": 1 } }
```

`type`: `attack` (`cards`), `throwIn` (`cards`), `beat` (`card`, `on` — номер карты атаки), `transfer` (`cards`),
`take`, `give` (`cards`, вдогонку), `pass`, `done`.

- `200 {"n": 18}` — принято; новое состояние придёт событием.
- `409 stale {"table": TableView}` — действие с этим `n` уже было (кто-то подкинул раньше): телефон показывает
  свежий вид, недоделанное действие отменяется.
- `400 illegal {"reason": "transfer-too-many"}` — незаконно; причина — та же, что движок даёт интерфейсу.
- Повтор с тем же `n` и тем же действием — тот же ответ, без второго применения.

Сдача, реванш, фразы — как в «Нардах»: `POST /v1/tables/:id/resign`, `…/rematch`, `…/say`.

## Быстрая игра

Как в «Нардах» (`POST /v1/quick`, опрос, отмена), плюс `variant` в запросе: пары подбираются только с одним
вариантом. Два места, рейтинг Glicko-2 отдельно для подкидного и переводного.

## События (WebSocket)

Как в «Нардах», но **каждое событие собирается для места**: сервер держит соединения по местам и рассылает каждому
его версию. События: `seat` (кто сел или вышел из сети), `start` (новая партия, вид места, `commit`), `act`
(номер, кто и что сделал, новый вид места; карты, которые сыграли в открытую, видны всем, добор — только
свой), `bout` (конец отбоя: «бито» или «беру»), `end` (итог, `proof`, `nextCommit`), `say` (фраза).

Добор показывается чужим только числом: «Саша взял 2 карты».

## Ошибки, которых нет в «Нардах»

| Код | Когда |
|---|---|
| `full` | за столом нет мест |
| `not-enough` | начать нельзя: один игрок и боты выключены |
| `stale` | действие с этим номером уже было |
| `illegal` + `reason` | действие против правил; `reason` — код причины из движка |
| `not-your-turn` | не ваш черёд: вы не атакующий или не отбивающийся в этом отбое |
