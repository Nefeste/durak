# Протокол сервера

Сервер — `durak.gornitsa.games` (машина сайта в России, решение владельца #6). Код — `server/src/`, общие с
телефоном типы — `src/state/protocol.ts`, колода — `src/engine/deck.ts`. Устройство взято из «Нард»
([`Nefeste/nardy`, `docs/03-server-api.md`](https://github.com/Nefeste/nardy/blob/main/docs/03-server-api.md)):
ключ устройства, ник, коды столов, пределы, коды ошибок, повтор запроса, страницы сайта. Отличия от «Нард»: за
столом **2–4 места**, сервер отдаёт **вид места**, а не всю партию (ADR [0008](adr/0008-server-per-seat-views.md)),
и случайность — это **порядок колоды** (ADR [0004](adr/0004-deck-source.md)).

## Общее

- Каждый запрос с ключом несёт `Authorization: Bearer <ключ>` и `X-Durak-Version: <версия игры>`. Версия старше
  `MIN_APP` — `426 upgrade {"need": "…"}`.
- Ответ с ошибкой — `{"error": "<код>", …}` и код HTTP из таблицы `ERRORS` в `protocol.ts`.
- Онлайн — с 14 лет (ADR студии 0016): без отметки «Мне есть 14 лет» телефон не шлёт ничего, кроме `/v1/ping`.

| Запрос | Что |
|---|---|
| `GET /v1/ping` | `{"ok": true, "v": "<протокол>", "now": <мс>}` |
| `POST /v1/device` | новый ключ устройства `{"key"}` (без ключа; не чаще 10 в час с адреса) |
| `POST /v1/session` `{"name"}` | завести профиль или сменить ник → `{"id", "name", "tag"}` |
| `POST /v1/profile/delete` | стереть ник и ключ; за его места дальше играют боты, в быстрой игре — сдача |
| `POST /v1/report` | отчёт «Сообщить об ошибке» (до 16 КБ, хранится 180 дней) |

## Столы

Стол — встреча 2–4 мест. `kind`: `friend` — с друзьями по коду, `quick` — быстрая игра (два места). У стола
`version` — растёт с каждым изменением; `game.no` — номер партии за столом с нуля, `game.n` — номер следующего
действия партии.

### Создать и сесть

1. `POST /v1/tables` `{"rid", "variant": "podkidnoy"|"perevodnoy", "seats": 2…4, "bots": "<уровень>"|null}` →
   `201 {"table": TableView}`. Создатель — место 0. `bots` — кто сядет на свободные места при «Начать»; `null` — никто.
   Повтор с тем же `rid` возвращает тот же стол.
2. Сесть — в два шага, и **создатель тоже**: телефон записывает отпечаток колоды до того, как отдаёт своё зерно.
   - `GET /v1/tables/code/<КОД>` → `CodeInfo` `{"id", "host", "variant", "seats", "taken", "status", "commit", "mine"}`;
   - `POST /v1/tables/join` `{"code", "seed": "<16 байт hex>", "commit"}` → `{"table": TableView}`. `409
     commit-changed {"commit"}` — отпечаток сменился; `409 full` — мест нет. Уже сидящий за столом этим запросом
     только отдаёт зерно.
3. `POST /v1/tables/:id/start` — создатель стола с друзьями начинает партию. Сидящий без зерна выбывает; пустые
   места занимают боты уровня `bots`, а если `bots` нет — `409 not-enough` при одном игроке. Стол быстрой игры
   начинается сам, когда оба отдали зёрна.
4. `POST /v1/tables/:id/cancel` — создатель закрывает стол до начала.

### Колода

Зерно сервера — 32 байта, отпечаток — `SHA-256(зерно)`; он есть в `TableView.game.commit` и в `CodeInfo` до того, как
место отдаёт зерно. Зёрна ботов делает сервер при раздаче. Порядок колоды — `durak-deck-v1` от зерна сервера и
зёрен всех мест по порядку мест (`serverDeck`). Первый ход — по своду: младший козырь, в следующих партиях — после
дурака (`firstOf`, `nextFirst`).

### `TableView` — что видит место

```json
{
  "id": "t_9x…", "kind": "friend", "code": "K7M2QX", "status": "playing", "variant": "perevodnoy",
  "rules": "durak-rules-v1", "host": 0, "bots": "average", "you": 1, "version": 42,
  "seats": [
    { "name": "Миша", "tag": "AB12CD", "bot": null, "botFor": false, "online": true, "cards": 6, "out": false },
    { "name": "Саша", "tag": "CD34EF", "bot": null, "botFor": false, "online": true, "cards": 5, "out": false },
    { "name": "", "tag": null, "bot": "average", "botFor": false, "online": true, "cards": 6, "out": false }
  ],
  "game": {
    "no": 0, "commit": "e3b0…", "n": 17, "view": { "seat": 1, "hand": [3, 12, 20, 27, 31], "...": "…" },
    "waiting": [1], "deadline": 1790000020000, "banks": [60000, 52000, 60000],
    "result": null, "proof": null, "nextCommit": null, "rematch": [false, false, false]
  }
}
```

- `view` — **ровно** `observe(позиция, you)` движка: своя рука, сколько карт у каждого, взятое в открытую, козырь,
  сколько в прикупе, стол, сброс, кто ходит и отбивается, кто сказал «пас», номер отбоя, вышедшие, итог. **Чужих рук
  и порядка прикупа здесь нет никогда** (ADR 0008; тест `tools/test/server.test.ts` пересобирает позицию из
  доказательства и сверяет каждый вид, который получил каждый игрок).
- `seats[i]` — `null`, пока место свободно. `bot` — уровень бота за местом; `botFor` — за человека сейчас играет бот
  «играет бот за Имя» (нет связи 30 с или трижды решили часы); `rating` — у мест быстрой игры.
- `waiting` — чьего действия ждут; `deadline` — до какого времени ждут **вас** (20 с на действие плюс запас,
  `banks`); `null` — не вас.
- После партии: `view: null`, `result` `{"fool": 2 | null, "draw", "order"}`, `proof` (ниже), `nextCommit` — отпечаток
  следующей партии, `rematch` — кто нажал «Реванш». `status: "finished"`.

### Доказательство

`proof` в итоге и `GET /v1/tables/:id/proof?game=<номер>`:
`{"commit", "seed", "seeds": [...], "deck": [36 карт], "first", "actions": [{"seat", "action"}], "algo": "durak-deck-v1"}`.
Телефон (`src/state/verify.ts`) сверяет отпечаток, **записанный им до своего зерна**, своё зерно на своём месте,
колоду из зёрен и каждое наблюдение, которое видел за партию, с позицией, переигранной из `actions`.

### Действие

`POST /v1/tables/:id/act` `{"game": 0, "n": 17, "action": {...}}` → `200 {"n": 18}`.

Действия — как в движке (`src/engine/types.ts`): `attack` и `throwIn`, `give`, `transfer` — `{"cards": [...]}`;
`beat` — `{"card", "on"}`, где `on` — **карта** атаки; `take`; `pass`. Отдельного «бито» нет: отбой закрывает
движок, когда все атакующие сказали «пас».

- `409 stale {"table"}` — действие с этим `n` уже было (кто-то подкинул раньше) или `game` не та: свежий вид,
  недоделанное действие отменяется.
- `409 not-your-turn {"reason": "notYourMove"}` и `400 illegal {"reason": "<причина движка>"}` — та же причина,
  что движок даёт экрану (`T.reason`).
- Повтор с тем же `n` и тем же действием — тот же ответ, без второго применения.

### Часы, «бито» само, боты

Числа — `ONLINE` в `protocol.ts` и `docs/09-game-design.md`, «Онлайн»:

- **Время на действие** — 20 с, сверх него тратится запас на партию (60 с). Кончился — за место простейшее
  законное (`simplest`): отбивающийся берёт, атакующий говорит «пас», на пустой стол — младшая карта. Три раза
  подряд: быстрая игра — поражение, стол с друзьями — дальше за место играет бот, пока игрок не сделает ход сам.
- **«Бито» само** — место, которому подкинуть нечего, говорит «пас» через 1,5 с; бот говорит «пас» с той же паузой:
  мгновенное «бито» выдало бы, что подкинуть нечем.
- **Нет связи 30 с** за столом с друзьями — за место играет бот «играет бот за Имя»; вернулся (любой запрос стола) —
  снова сам. Уровень — «Мастер», сильнейший (`standInLevel`).
- Боты стола и боты «за Имя» видят только наблюдение своего места (тот же `src/bot/`).

### Прочее за столом

- `POST /v1/tables/:id/resign` — быстрая игра: поражение; стол с друзьями: за вас доигрывает бот.
- `POST /v1/tables/:id/rematch` `{"seed", "commit"}` — «Реванш» по уже показанному `nextCommit`; когда нажали все
  люди за столом, следующая партия начинается сама.
- `POST /v1/tables/:id/say` `{"msg": "<ключ фразы>"}` — готовая фраза из `CHAT`; свободного текста нет.
- `GET /v1/tables/:id?since=<version>` — опрос: `{"unchanged": true}` или `{"table": TableView}`. Любой запрос стола
  отмечает место «в сети».

## Быстрая игра

- `POST /v1/quick` `{"variant"}` — встать в очередь (повтор безопасен) → `QuickView`;
  `GET /v1/quick` — опрос; `POST /v1/quick/cancel`.
- `QuickView`: `{"status": "idle", "me"}` | `{"status": "searching", "since", "offerBot", "me"}` | `{"status": "matched",
  "table"}`. `me` — `{"rating", "provisional", "games"}` по варианту.
- Пара — ближайшие по рейтингу Glicko-2 одного варианта в окне 100 + 10 за секунду ожидания. Найдена — стол `quick`
  с обоими местами; телефоны садятся по коду, как к друзьям (зерно — после отпечатка). Не сели за 30 с — стол
  закрыт.
- Через 60 с поиска `offerBot: true`; `POST /v1/quick/bot` — стол против бота «Средний» с подписью «бот», без
  рейтинга. Молча бот не садится никогда.
- Рейтинг — отдельно для подкидного и переводного, после каждой партии двух людей; ничья — 0,5.

## WebSocket `/v1/live`

Ускоритель опроса, как в «Нардах». Телефон: `{"t": "hello", "key", "v", "table"}`, потом `{"t": "ping"}` (место — «в
сети»). Сервер шлёт `{"t": "state", "table": TableView}` — **вид своего места** при каждом изменении стола (каждому
соединению свой, ADR 0008), `{"t": "say", "seat", "msg"}`, `{"t": "pong"}`, `{"t": "error", "code"}`. Не больше
четырёх соединений на ключ. Нет WebSocket — телефон опрашивает стол раз в 1,5 с (`src/state/online.ts`).

## Страницы сайта

- `/t/<КОД>` — приглашение за стол: «Открыть в приложении» (App Link `https://durak.gornitsa.games/t/<КОД>`, в Chrome
  — intent) или поставить игру и ввести код.
- `/fair` — как устроена колода и как проверить её самому.
- `/.well-known/assetlinks.json` — App Links, если задан отпечаток сертификата подписи (`cert.sha256` рядом со
  сборкой, его пишет `server.yml` из `ANDROID_CERT_SHA256`).
- `/` и `/privacy` — переадресация на gornitsa.games.

## Ошибки, которых нет в «Нардах»

| Код | Когда |
|---|---|
| `full` | за столом нет мест |
| `not-enough` | начать нельзя: один игрок и боты выключены |
| `stale` | действие с этим номером уже было или партия не та |
| `illegal` + `reason` | действие против правил; `reason` — код причины из движка |
| `not-your-turn` | не ваш черёд |
| `bad-variant`, `bad-seats`, `bad-level`, `bad-action` | неверное поле запроса |
| `not-host`, `not-waiting`, `not-playing`, `not-finished` | действие не к месту |
