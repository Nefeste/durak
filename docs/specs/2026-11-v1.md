# Спецификация 1.0.0 — первый выход в RuStore

**Версия:** 1.0.0 **Состояние:** этапы А и Б сделаны 08.11.2026 (журнал проверок внизу). Решение владельца 08.11.2026 (`Nefeste/uprava#80`, вариант 1).
**Срок:** на модерации RuStore 05–07.12.2026, в RuStore до 14.12.2026 — к рекламе студии 20.12–08.01.

Разделы — по уставу ([`11-new-games.md`](https://github.com/Nefeste/gornitsa/blob/main/docs/11-new-games.md)).

## 1. Зачем

Выпустить дурака, которого стоит поставить вместо лидеров с миллионом скачиваний: честная колода, бот, который не
подглядывает, разбор, задача дня, стол по ссылке на всю семью и реклама, которая не мешает. Ответить на вопрос:
**доигрывают ли первую партию и возвращаются ли на второй день** — с праздничной рекламой это будет видно за неделю.

## 3. Сквозной путь игрока

| № | Шаг | Время |
|---|---|---|
| 1 | Установил из RuStore, открыл — заставка без белой вспышки, главный экран | 3 с |
| 2 | «Играть» — первая партия против «Начинающего», подкидной вдвоём, подсказки первых трёх отбоев | 4 мин |
| 3 | Итог: «вы вышли первым» или «остались с картами», главная ошибка, «Ещё партию» | 15 с |
| 4 | Вторая партия: переводной, двое ботов; окно «что такое перевод» | 5 мин |
| 5 | «Разбор» последней партии: ошибка, лучший ход, «почему» | 1 мин |
| 6 | «Задача дня»: решил со второй попытки, поделился текстом | 2 мин |
| 7 | «С друзьями» → стол на четверых, ссылка в мессенджер; двое родственников вошли по ссылке, четвёртое место — бот | 2 мин |
| 8 | Партия вчетвером онлайн, «Колода проверена ✓» на итоге, «Реванш» | 8 мин |
| | **Итого** | **~23 минуты** |

Этот путь проходит сценарий в браузере целиком (онлайн — три браузера).

## 5. Обёртка

Главный экран с названием и рубашкой; загрузка не нужна (всё в APK); «Правила» своими словами с картинками;
итог партии с главной ошибкой; статистика; «Об игре» со знаком студии; снимки магазина и короткий ролик — скриптом,
как `tools/store/shots.ts` и `video.ts` «Нард».

## 6. Жизнь стола

Звуки с видимой причиной: тасовка при раздаче, шлепок карты, шорох «бито», вздох колоды при «беру». Соперники:
значок «думает», веер рубашек, число карт. Больше — ничего.

## 7. Графика и звук

Карты, рубашка, стол — код (ADR [0010](../adr/0010-cards-in-code.md)). Шрифт — брендбук. Звуки — записи CC0 с
паспортом (`assets/sounds/SOURCES.md`, как у «Нард»). Иконка — код (`src/render/appIcon.ts`, как у «Нард»).

## 9. Чего в 1.0 нет

Нейросети в «Мастере» (1.1); выводов из поведения соперников в раскладах (1.1); друзей-списка (как в «Нардах», 1.2);
командной игры, 5–6 игроков, колоды на 52; английского; iOS и веба для игроков; вдвоём на одном телефоне.

## 10. Критерии готовности

1. Золотые тесты всех пунктов `08-rules.md`, 100 000 случайных партий без нарушения инвариантов, сверка быстрого и
   медленного перебора.
2. Тест одинаковости ботов и правило линтера «бот не видит колоду» — зелёные.
3. Тест вида места сервера — ни один маршрут и ни одно событие не несёт чужой руки.
4. Колода `durak-deck-v1`: векторы совпадают в Bun, Node и Hermes; подмена карты ловится.
5. Арена: лестница уровней — каждый соседа ≥ 60 % один на один; отчёт в `docs/reports/`.
6. Задача дня: 400 задач, у каждой одно спасающее первое действие.
7. Сквозной путь (раздел 3) проходит сценарий в браузере целиком; ошибок в консоли нет; снимки просмотрены.
8. Деньги: правила частоты рекламы — тесты; покупка в тестовом режиме RuStore — у владельца.
9. Замер на целевом телефоне: кадр и скорость ботов по разделам 4 и 8 — в журнал.
10. **Игра владельца** на телефоне: с ботами, переводной вчетвером и стол по ссылке хотя бы с одним человеком.

## 11. Вопросы к игре владельца

- Хочется ли сыграть ещё одну партию сразу после итога?
- Понятно ли, почему проиграли, — из строки главной ошибки, без разбора?
- Чувствуется ли «Мастер» сильным, а «Новичок» — слабым, но не глупым?
- Не раздражает ли что-то в руке и кнопках одной рукой?
- Позвали бы вы этим столом родных на Новый год?

## 12. Колода — `durak-deck-v1`

Устроено как кубики «Нард» ([`nardy/docs/specs/2026-09-fair-dice.md`](https://github.com/Nefeste/nardy/blob/main/docs/specs/2026-09-fair-dice.md)),
но поток байтов тасует колоду.

- **Входы:** `serverSeed` — 32 байта; `seed_i` — 16 байт hex от телефона каждого места `i` по порядку мест.
- **Отпечаток:** `commit = hex(SHA-256(serverSeed))` — телефон записывает его **раньше**, чем отдаёт своё зерно.
- **Поток:** `B_k = HMAC-SHA-256(key = serverSeed, message = "durak-deck-v1|" + seed_0 + "|" + … + "|" + seed_{n−1} + "|" + k)`,
  `k = 0, 1, 2, …`; поток — `B_0 ‖ B_1 ‖ …`.
- **Тасовка:** колода `[0 … 35]`; Фишер — Йетс сверху вниз: для `i = 35 … 1` берётся число `j` из `[0 … i]`
  отбрасыванием: из потока читаются 2 байта как `x` (big-endian), если `x ≥ 65536 − 65536 mod (i+1)` — пропуск,
  иначе `j = x mod (i+1)`; меняются `deck[i]` и `deck[j]`.
- **Раздача:** карты берутся с начала массива по одной, по местам 0, 1, …, n−1 по кругу, по шесть каждому;
  следующая — козырь, остальные — прикуп сверху вниз, козырь — последний.
- **Проверка:** после партии телефон получает `serverSeed` и зёрна, пересобирает колоду, проверяет `commit` и каждую
  карту, которую видел, с местом и моментом.
- **С ботами** — то же построение из 32 байт `expo-crypto` в момент раздачи, без отпечатка (проверять некому).
- **Векторы** — `tools/test/fixtures/deck-v1.json`, их проверяют Bun, Node и Hermes.

## 13. Решения агента

| Что | Почему | Как переделать |
|---|---|---|
| Портрет | рука веером и игра одной рукой | ADR 0007; новая раскладка экранов |
| Подкидывают все сразу, первым кто успел | очередь словами в приложении невозможна | правило в `08-rules.md` п. 4.3 и `legal.ts` |
| Пауза 1,5 с перед «бито» | успеть подкинуть; мгновенное «бито» выдаёт карты соперников | число в `09-game-design.md`, «Темп» |
| Итог «остались с картами», не «вы дурак» | тон студии, слово не нравится владельцу | строки `src/i18n/` |
| Стол по ссылке до четырёх, быстрая игра — вдвоём | новогодний сценарий — семья; подбор четверых по рейтингу медленный | `03-server-api.md`, быстрая игра |
| Помощники против ботов — бесплатно | устав запрещает продавать силу и в одиночной игре | `09-game-design.md` |
| Сильный бот — поиск по раскладам, нейросеть — 1.1 | пять недель; поиск даёт силу сразу, сеть нужно учить | `10-bot.md` |
| Колода — Фишер — Йетс по HMAC | тот же приём, что кубики «Нард», проверяемый и простой | раздел 12, новая версия `durak-deck-v2` |
| Карты 0…35, масти ♠ ♣ ♦ ♥ | компактно для битовых масок решателя | `04-data-model.md` |
