# Магазин и сайт: карточка RuStore, анкеты, графика, страница игры

Всё, что нужно, чтобы завести карточку «Козыря» в RuStore и страницу на gornitsa.games. Тексты — по голосу
студии (устав, `docs/09-voice.md`); каждое утверждение — про то, что в игре уже есть.

| Файл | Что |
|---|---|
| [`listing.ru.md`](listing.ru.md) | название, краткое и полное описание, «Что нового» — копируются в консоль RuStore как есть |
| [`forms.md`](forms.md) | анкеты RuStore: возраст, данные, разрешения Android, товары RuStore Pay |
| `graphics/` | значок 512, баннер 1024 × 500, картинка для ссылок 1200 × 630 |
| `screenshots/ru/` | снимки 1080 × 1920 (портрет): партия, «почему нельзя», итог, переводной, вышедшие карты, меню, настройки, разбор на столе, задача дня, подсказка, «Путь к Мастеру» и коллекция |
| `video/kozyr-ru.mp4` | ролик 1920 × 1080, около минуты, без звука — **в git не кладётся**: его загружают на видеохостинг, ссылку вписывают в карточку |
| [`site/page.ru.md`](site/page.ru.md), [`site/page.en.md`](site/page.en.md) | страница игры на gornitsa.games (устав, `docs/08-publishing.md`, «Сайт») |

Графику, снимки и ролик делают скрипты, руками их не правят (ADR 0023 устава, правило 3):

```bash
EXPO_OFFLINE=1 npm run export:web
NODE_PATH=/opt/node22/lib/node_modules bun tools/store/shots.ts   # graphics/ и screenshots/ru/
NODE_PATH=/opt/node22/lib/node_modules bun tools/store/video.ts   # video/kozyr-ru.mp4 (нужен ffmpeg)
```

Снимки и ролик снимаются с веб-сборки настоящими касаниями против ботов; раздачи случайные — от прогона к
прогону кадры разные, подписи к ним (`site/page.*.md`) от раздачи не зависят. Ролик: экран телефона посреди кадра
16:9, слева название, справа подпись к тому, что на столе: меню → подкидной вдвоём касаниями (раздача, «почему
нельзя», подсказка «Опытного») → переводной вчетвером → итог с главной ошибкой → разбор на столе → задача дня →
карточка конца. Звука в ролике нет: в веб-сборке игра молчит.

## Карточка в RuStore — шаги владельца

1. Консоль RuStore → «Приложения» → новое: пакет `games.gornitsa.durak` (навсегда), APK из релиза тега.
2. Тексты — из [`listing.ru.md`](listing.ru.md), графика и снимки — из этой папки, анкеты — по [`forms.md`](forms.md).
3. RuStore Pay: товары из [`forms.md`](forms.md), «Товары». Номер приложения из консоли — переменная сборки
   `EXPO_PUBLIC_RUSTORE_APP_ID` (Settings → Secrets and variables → Actions → Variables).
4. Реклама: два блока в кабинете Рекламной сети Яндекса (межстраничный и с вознаграждением) — переменные
   `EXPO_PUBLIC_YANDEX_ADS_INTERSTITIAL` и `EXPO_PUBLIC_YANDEX_ADS_REWARDED`. Без них сборка показывает
   демонстрационную рекламу Яндекса и денег не приносит.
5. Ссылки: политика — https://gornitsa.games/privacy.html#durak, поддержка — https://gornitsa.games/support.html.
