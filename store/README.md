## Карточка в RuStore — шаги владельца

1. Консоль RuStore → «Приложения» → новое: пакет `games.gornitsa.durak` (навсегда), APK из релиза тега.
2. Тексты — из [`listing.ru.md`](listing.ru.md), графика и снимки — из этой папки, анкеты — по [`forms.md`](forms.md).
3. RuStore Pay: товары из [`forms.md`](forms.md), «Товары». Номер приложения из консоли — переменная сборки
   `EXPO_PUBLIC_RUSTORE_APP_ID` (Settings → Secrets and variables → Actions → Variables).
4. Реклама: два блока в кабинете Рекламной сети Яндекса (межстраничный и с вознаграждением) — переменные
   `EXPO_PUBLIC_YANDEX_ADS_INTERSTITIAL` и `EXPO_PUBLIC_YANDEX_ADS_REWARDED`. Без них сборка показывает
   демонстрационную рекламу Яндекса и денег не приносит.
5. Ссылки: политика — https://gornitsa.games/privacy.html#durak, поддержка — https://gornitsa.games/support.html.
