## Разрешения Android

Белый список — `.github/apk-permissions.txt`: `android.yml` не выпустит APK с другим разрешением. Список
— как у «Нард» (сборка 78 — первая с RuStore Pay и рекламой Яндекса), но без Install Referrer: он запрещён в
`app.json` и в `android.yml` (тег `v0.2.0`). Первый тег с рекламой сверит список с настоящим APK.

| Разрешение | Зачем |
|---|---|
| `INTERNET`, `ACCESS_NETWORK_STATE` | игра онлайн, реклама, покупки |
| `VIBRATE` | вибрация при своих ходах (выключается в настройках) |
| `MODIFY_AUDIO_SETTINGS` | служебное библиотеки звука `expo-audio` |
| `WAKE_LOCK`, `RECEIVE_BOOT_COMPLETED` | служебные React Native и SDK |
| `com.google.android.gms.permission.AD_ID` | рекламный идентификатор для Рекламной сети Яндекса |
| `games.gornitsa.durak.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` | служебное Android, само приложение |

Явно запрещены в `app.json`: память (`READ/WRITE_EXTERNAL_STORAGE`), окна поверх других, микрофон, фоновое
воспроизведение и служба Install Referrer (`BIND_GET_INSTALL_REFERRER_SERVICE`).

## Какие данные собираются

Партии с ботами, настройки и покупки (кэш) хранятся только на телефоне. «Сообщить об ошибке» — игрок видит весь
отчёт и сам отправляет его. С сервером онлайна (Москва, [`../docs/03-server-api.md`](../docs/03-server-api.md),
[`../docs/04-data-model.md`](../docs/04-data-model.md)):

| Что | Зачем | Сколько хранится |
|---|---|---|
| Ник, тег, хеш ключа устройства | игра онлайн | до удаления профиля игроком. Сервер это умеет (`POST /v1/profile/delete`), кнопки в игре и страницы удаления на сайте ещё нет — до неё удаляют по письму на `support@gornitsa.games`; кнопка — задача к 1.0 |
| Рейтинг онлайна по вариантам | быстрая игра: подбор соперника по рейтингу | до удаления профиля |
| Столы и партии онлайн: места, зёрна колоды, действия, итог | игра, восстановление после перезапуска сервера, проверка колоды | стол, где никто не сел, — сутки; законченные — 30 дней |
| Отчёт об ошибке (если игрок сам отправил) | исправление ошибок | 180 дней |
| Рекламный идентификатор | обрабатывает SDK Яндекса при показе рекламы; переключатель «Персональная реклама» в настройках | у Яндекса, по его правилам |

**Не собираются:** почта, телефон, контакты, местоположение, фото и файлы, микрофон. Аналитических SDK и
статистики на сервере нет. Свободного чата нет: сервер не принимает от игроков текста, кроме ника.
